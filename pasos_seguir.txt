# Tienda online en Java Swing

Aplicación de escritorio al estilo Amazon, desarrollada como proyecto académico de DAW. Tiene dos tipos de usuario, cliente y administrador, y guarda los datos en una base de datos SQL.

## Funcionalidades

**Cliente**
- Catálogo de productos con filtros y vista de detalle.
- Carrito de la compra y pago con tarjeta.
- Historial de pedidos.
- Envío de quejas.
- Mensajes de error personalizados (tarjeta no válida, stock insuficiente).

**Administrador**
- Edición de todo tipo de productos.
- Consulta de la información de la tienda.

**Login:** según el tipo de usuario, se accede a la parte de cliente o a la de administrador.

## Cómo está organizado

- **Modelo:** clases que representan los datos de la tienda.
- **DAO:** clases que se conectan a la base de datos para consultar y guardar información.
- **Interfaz:** ventanas de Java Swing para cliente y administrador.
- **Main:** punto de entrada de la aplicación.

## Base de datos

Tablas: `usuarios`, `productos`, `pedidos`, `tarjetas` y `quejas`.

## Reto principal

Controlar el stock para que no se pueda comprar más cantidad de la que hay disponible. Fue la parte en la que más tiempo dediqué.
